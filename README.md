# Customer Churn Prediction & Retention Intelligence System

A Machine Learning project focused on predicting customer churn, understanding customer behaviour, identifying potential churn risks, and supporting data-driven customer retention strategies.

## 📌 Project Overview

Customer churn is a major challenge for subscription-based businesses, particularly in the telecommunications industry.

This project explores how Machine Learning techniques can help identify customers who are likely to discontinue a service. It uses customer data to investigate churn patterns and develop predictive models that can support better business decisions.

The project is based on the IBM Telco Customer Churn dataset.

## 🎯 Project Objectives

- Analyse customer behaviour and churn patterns.
- Perform data cleaning and exploratory data analysis.
- Identify important factors associated with customer churn.
- Develop Machine Learning models for churn prediction.
- Evaluate and compare model performance.
- Explore explainable AI techniques to interpret predictions.
- Support customer retention planning through predictive insights.

## 🤖 Machine Learning Algorithms

The project explores the following algorithms:

- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting
- XGBoost

## 📊 Explainable AI

SHAP (SHapley Additive exPlanations) is considered for interpreting model predictions and understanding how individual features influence churn risk.

## 📂 Dataset

**IBM Telco Customer Churn Dataset**

The dataset contains telecommunications customer information, including demographic details, subscribed services, account information, and churn status.
